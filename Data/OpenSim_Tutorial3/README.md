# Data from OpenSim Tutorial 3

- Tutorial 3 is available online ([link](https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53089860/Getting+OpenSim)).
- The data for Tutorial 3 is available in the `Gait2354_Simbody` folder. On Windows, this folder is available by default at `Documents\OpenSim\4.6\Models`.

# Python

`Python/scale_ik_id.py` runs the same three steps as Tutorial 3 — Scaling,
Inverse Kinematics (IK), and Inverse Dynamics (ID) — using the OpenSim Python
API, then reads back and plots the results (marker errors, knee moments)
into `Output/`.

The joint angles, ground reaction forces, and scaled-model anthropometric
data this produces are the inputs to
[`Assignments/A3/calculate_knee_torque.py`](../../Assignments/A3/calculate_knee_torque.py),
which loads them as NumPy arrays -- along with the 2-segment (foot + shank)
model's own dimensions and joint-angle velocities/accelerations, already
extracted and differentiated -- for a first-principles knee torque
calculation. Run `scale_ik_id.py` first.

## Note
The `.xml` configuration files in this repo have been updated to accommodate a different folder structure from the original Tutorial 3:

- `Setup/` — configuration files, already filled in for this folder layout
- `Data/` — input data (markers and ground reaction forces). Tracked in git
  but marked `skip-worktree`: `scale_ik_id.py` overwrites some of these
  files in place (e.g. `subject01_scaledOnly.osim`), and git is told to
  ignore those local changes rather than flag them as modifications.
- `Geometry/` — a handful of gait2354's `.vtp` body-shape meshes, bundled
  here purely so the OpenSim API doesn't warn about missing display
  geometry when it loads the model. Also tracked with `skip-worktree`.
- `Output/` — gitignored; regenerated by running `Python/scale_ik_id.py`.
